Qu-01:What is JSX, and why is it used?
Solution: JSX is a syntax that looks like HTML but is used in React to create UI elements easily.

Qu-02:What is the difference between State and Props?
Solution: State is data inside a component that can change, while Props are passed to a component from outside and cannot be changed.

Qu-03:What is the useState hook, and how does it work?
Solution: useState is a React hook to add state to a component; it gives a value and a function to update it.

Qu-04:How can you share state between components in React?
Solution: You can share state by lifting it up to a common parent and passing it via props.

Qu-05:How is event handling done in React?
Solution: In React, you handle events using camelCase props like onClick and pass a function to them.
